# Offline Mode — Known Issues & Fix Tracker

> **Purpose:** single place to track the offline bugs found during the October 2026 offline review: what's wrong, how it was reproduced, the agreed fix, and its status.
> **How to use:** work through the issues in priority order. When an issue is fixed and verified, set its status to ✅ **Done** and fill in the "Fixed in" column.
> **Related:** [`offline-local-testing.md`](offline-local-testing.md) (how to test offline locally) · [`offline-first-architecture.md`](../../features/offline-first-architecture.md) (design)

## 3. How the Issues Were Reproduced (2026-10-10)

**Setup:** the `frontend-pwa` container on `http://localhost:5174` (production build with service worker), driven by **Playwright + Chromium** with the local test accounts. Offline was simulated with Playwright's `context.setOffline(true)`.

The built-in browser of the Claude desktop app **can't register service workers**, so it isn't usable for offline testing. Use a real Chrome/Chromium or Playwright.

**Safety:** no real data was changed. Outbox items were written in the exact shape `enqueue()` produces, pointing at endpoints the server rejects. The one test record created (a custom KPI) was deleted afterwards.

| ID  | Steps                                                                                                                                 | Observed                                                                                                                                            |
| --- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| A   | Log in (ministry), then remove `submission-<id>` from IndexedDB **and** the persisted query snapshot, go offline, open the submission | "This page didn't load". Console: `TypeError: Cannot read properties of undefined (reading 'slice')`                                                |
| A   | Log in (apex), go offline, open the submissions list, then a submission                                                               | "This page didn't load". Console: `TypeError: j.filter is not a function` (chart of accounts)                                                       |
| B   | Log in (cooperative / apex), go offline, open the submissions list                                                                    | "New Submission" button is enabled                                                                                                                  |
| C   | Log in, go offline, **reload**, queue an item, go online, wait 30s                                                                    | Item still `pending`, 0 attempts. Banner still says "You're offline". Control (no reload) is processed.                                             |
| D   | Create a custom KPI online. Let the request reach the server but drop the reply, then let the outbox retry                            | 1st attempt: 201, no `X-Correlation-Id`. Retries: same ID each time, server tries to insert again → `duplicate key … custom_kpis_name_key` (500) ×5 |
| E   | Queue `POST /api/v1/users` with an existing email, go online                                                                          | Server: 409 "User with this email already exists" → item marked `done`                                                                              |
| F   | Queue `PATCH /api/v1/organizations/{unknown id}`, go online                                                                           | 404 ×5 within 12s → `failed`, `lastError` empty, nothing shown on screen                                                                            |
| G   | Log in (apex) without opening any members page, go offline, open a cooperative's members                                              | Seeder saved 3 members. Page shows "0 members". Online shows 3.                                                                                     |
| H   | Open the members page offline, then go online and reload                                                                              | Still shows "0 members"                                                                                                                             |
| I   | Any session                                                                                                                           | Console warning `[persister] Failed to persist QueryClient to IndexedDB: DataCloneError`                                                            |
